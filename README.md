# 地震台站数据质量检测服务

纯后端 Node.js + TypeScript + Fastify 服务，面向地震台站观测数据接入与质量检测。

## 能力

- 台站档案管理
- 观测摘要批量接入
- 采样完整性、波形削顶、时间同步检测
- 质量评分与问题标签
- 按台站/分数查询观测记录
- 生成时间窗口质量报告

## 观测接入语义

实时与补传观测可能交错到达，接入按统一状态规则处理，保证台站档案、观测记录与质量报告一致：

- **迟到观测**：正常入库参与质量统计，但 `lastSeenAt` 只单调前进、不回退；
- **重复观测**：同台站同一观测时刻幂等处理，返回 `200` 与已存在记录，不重复计数；
- **维护期间**：观测正常入库，`maintenance` 为人工管理状态，不被观测自动改为 `online`；
- **状态恢复**：`offline` 台站仅在收到不早于已知 `lastSeenAt` 的最新观测时恢复 `online`。

## 启动

```bash
npm install
npm run dev
```

默认端口：`4301`。当前使用内存存储，后续可替换 PostgreSQL/时序数据库，并接入 Kafka、SeedLink 或对象存储。
